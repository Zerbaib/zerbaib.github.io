Volta.py

The official Python library for the Volta Music public API. A lightweight client with a clean client.get / post / put / delete interface to manage your library, playlists and the global catalog.

  • Automatic token management: fetch, refresh and persist to disk
  • Silent retry on 401 and background auto-refresh thread
  • Typed exceptions (NotFoundError, RateLimitError…)
  • Context manager for a clean shutdown, client-side search helpers
View the repository volta-music.com

Network & servers

Beyond code, I build and run my own infrastructure.

dn42-bgp.service

● dn42-bgp.service — I operate my own AS on DN42

Loaded: loaded (/etc/bird/bird.conf; enabled)

Active: active (running)

DN42 is a decentralized network run by enthusiasts that reproduces the technologies of the Internet: BGP, autonomous systems, IP allocations, DNS and a registry. I own an autonomous system on it: I manage my own address space, set up peering sessions with other operators and route traffic with BGP — exactly like an ISP, at home scale.

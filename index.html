Flagship Python REST API requests

Volta.py

The official Python library for the Volta Music public API. A lightweight client with a clean client.get / post / put / delete interface to manage your library, playlists and the global catalog.

  • Automatic token management: fetch, refresh and persist to disk
  • Silent retry on 401 and background auto-refresh thread
  • Typed exceptions (NotFoundError, RateLimitError…)
  • Context manager for a clean shutdown, client-side search helpers
View the repository volta-music.com
main.py
from VoltaLibPython import VoltaClient

with VoltaClient() as client:
    tracks = client.get.library.tracks(
        search="daft punk"
    )
    pl = client.post.library.playlist(
        "Roadtrip"
    )
    client.post.library.playlist_track(
        pl["id"], tracks[0]
    )

DN42 · BGP

I operate my own AS on DN42

I own an autonomous system on it: I manage my own address space, set up peering sessions with other operators and route traffic with BGP — exactly like an ISP, at home scale.
